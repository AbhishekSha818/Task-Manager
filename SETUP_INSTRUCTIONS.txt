=====================================
SMART TASK MANAGER - SETUP GUIDE
=====================================

Welcome! This is a production-ready task management app.
Follow these simple steps to get started.

PREREQUISITES:
- Node.js v18+ installed
- pnpm installed (run: npm install -g pnpm)
- MongoDB Atlas account (free tier available)

STEP 1: SETUP BACKEND
=====================
1. Open terminal/command prompt
2. Navigate to project: cd smart-task-manager
3. Go to backend: cd backend
4. Install dependencies: pnpm install
5. Start server: pnpm dev

Expected output:
  Server running on port 5000
  MongoDB connected successfully

STEP 2: SETUP FRONTEND (in another terminal)
============================================
1. Navigate to project: cd smart-task-manager
2. Go to frontend: cd frontend
3. Install dependencies: pnpm install
4. Start app: pnpm start

STEP 3: RUN THE APP
==================
After "pnpm start" in frontend:
- Press 'i' for iOS simulator
- Press 'a' for Android emulator
- Press 'w' for web browser
- Or scan QR code with Expo Go app (mobile)

TROUBLESHOOTING:
===============
Can't connect to backend?
- Ensure backend is running (pnpm dev in backend folder)
- Check port 5000 is not in use
- Verify MongoDB is connected (check backend logs)

App won't start?
- Clear cache: rm -rf node_modules package-lock.json
- Reinstall: pnpm install
- Try again: pnpm start
